## Forever Yours — Romantic Proposal Website

### Features
- Five attempts with different romantic questions
- Guard step: partner must type the exact proposer name (case‑insensitive)
- Sends result emails to both addresses
- Romantic animated background and responsive layout

### Use
Just open `index.html` in your browser. No backend required.

### Notes
- Click “Save This Moment” to get a reminder to capture a screenshot. No emails are sent.
- Files: `index.html`, `style.css`, `app.js`.
